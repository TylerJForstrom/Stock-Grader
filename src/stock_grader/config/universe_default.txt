# Default peer universe.
#
# Cross-sectional scoring needs a comparison group — a P/E of 22 means nothing until you know what
# peers trade at — so `stock-grader grade TICKER` loads this list when no --universe is given.
# It is a spread of large, liquid US filers across sectors, chosen so a grade has a sane reference
# distribution rather than any claim to be an index. Index membership is licensed data and is not
# something this project can ship.
#
# Replace it freely: a tighter, more comparable peer set gives a more meaningful grade. For a true
# peer group, use companies sharing the subject's SIC code.
